## About this site

I am Victor Yao. This site is where I publish practical troubleshooting guides, diagnostic techniques, and technical notes from real-world investigations.

The content currently focuses on:

- Browser technologies, including Microsoft Edge, Chrome, and WebView2.
- Windows diagnostics, networking, tracing, and event collection.
- IIS troubleshooting, performance analysis, and dump collection.
- .NET diagnostics in local and cloud-hosted environments.

## How the content is maintained

The guides are designed to be repeatable and easy to use during active troubleshooting. When a procedure depends on product behavior or a supported configuration, I link to official documentation where possible.

Technology changes over time. Each guide includes a last-modified date, but you should still verify that commands and interfaces apply to the product version you are testing.
