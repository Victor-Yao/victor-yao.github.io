## Troubleshooting and diagnostics guides

These guides are designed for use during active investigations. They focus on repeatable procedures, the evidence each procedure collects, and the conditions in which the technique is useful.

- [General diagnostics]({% link docs/general/index.md %}) — Windows tracing, networking, event logs, and system tools.
- [Browsers]({% link docs/Browsers/index.md %}) — Edge, Chrome, WebView2, browser policies, and diagnostic captures.
- [IIS]({% link docs/IIS/index.md %}) — IIS logging, Failed Request Tracing, dumps, ETW, and performance analysis.
- [.NET]({% link docs/dotnet/index.md %}) — .NET tracing and memory dump collection.

Before sharing collected data, review the [Disclaimer and Data Privacy guidance]({% link disclaimer.md %}).
