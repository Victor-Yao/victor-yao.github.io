## 从 iOS 上的 Edge 收集 Intune 帮助数据

1. 打开 Microsoft Edge，重现问题。

2. 转到 `edge://intunehelp`，然后点击 **Get Started**。

    ![开始使用](/assets/images/edgeios-intunehelp1.jpg)

2. 复制 **Reference ID**。然后点击 **Share Logs** 并将日志保存到本地。

    ![保存日志](/assets/images/edgeios-intunehelp2.jpg)
