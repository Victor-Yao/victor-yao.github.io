## 从 Edge Developer tools 收集 Console 日志

1. 打开 Microsoft Edge，然后按 **F12** 打开 **Developer tools**。

2. 选择 **Console** 选项卡，然后选择 **Clear console**。

   ![带 Clear console 选项的 Edge DevTools Console](/assets/images/edgeconsole1.png)

3. 重现问题。

4. 在 Console 输出中右键单击，然后选择 **Save as...**。

   ![Edge DevTools Console 输出的 Save as 选项](/assets/images/edgeconsole2.png)
